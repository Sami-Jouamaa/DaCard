# DaCard
Gotta collect them all.
Comes loaded with example cards.

## Features
- Collectable cards that can be found around the world.
- Card binders that can store your cards.
- Booster packs for card unboxing.
- Most of the numbers are configurable (proces, chances).
- Easy to use tools for custom Cards/Collections/Booster Packs creation with a layer system without having to bundle them in Unity.
- 3D cards.
- Rare layers are stickers: locked slots on the card, like attachments on a gun, each with its own price.
- Optional setup for mask and depth generation using ComfyUI for 3D cards.
- Safeguard for removed/broken cards/binders/booster packs that runs on server startup.

## DaCard Tools:
- Navigate to **SPT_Runtime\user\mods\Guro-DaCard** and open **DaCardDashboard.html** to use the tools for creation/editing of mod data.
